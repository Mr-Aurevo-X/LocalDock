À propos — LocalDock

Lanceur local-only pour serveurs de dev en loopback (Mr-Aurevo-X). Gratuit, sans compte. Pas de portail HTTP.

  • Seule connexion hors machine : vérif. version GitHub (option ci-dessous)
  • Si vérif. désactivée : zéro réseau hors actions utilisateur
